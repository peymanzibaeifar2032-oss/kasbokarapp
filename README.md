# کسب‌وکار — kasbokarapp.com

وب‌اپلیکیشن مستقل برای پیدا کردن کسب‌وکارهای محلی روی نقشه، رزرو نوبت، نظر، و پنل صاحب/مدیر.

این مخزن **منبع حقیقت** پروژه است. اجرای عادی به Grok یا محیط پیش‌نمایش وابسته نیست.

## امکانات

- نقشه و جست‌وجو (نمایش فقط کسب‌وکارهای تأییدشده با آزمایشی یا اشتراک فعال)
- ورود با ایمیل و رمز + بازیابی رمز (ایمیل Resend)
- ثبت کسب‌وکار، رزرو، نظر، پاسخ صاحب
- ۷ روز نمایش رایگان بعد از تأیید مدیر (فقط در سرور اعمال می‌شود)
- دوره نمایشی ۳۰ روزه تا وقتی درگاه پرداخت وصل شود
- راهنمای داخل برنامه و گزارش باگ
- علاقه‌مندی‌ها روی حساب (و روی همین دستگاه برای مهمان)

## اجرای مستقل (Production)

نیازها:

1. پایگاه Postgres پایدار (Neon / لیارا / پارس‌پک / Docker)
2. میزبانی Node 22 (Vercel یا Docker روی سرور)
3. دامنه `kasbokarapp.com` با HTTPS

متغیرهای لازم در `.env.example` آمده‌اند. حداقل:

- `STANDALONE=true`
- `DATABASE_URL`
- `BETTER_AUTH_SECRET`
- `BETTER_AUTH_URL=https://kasbokarapp.com`
- `SITE_URL=https://kasbokarapp.com`

### Vercel + Neon

1. مخزن را به Vercel وصل کنید (Import از GitHub، شاخه `main`).
2. متغیرهای محیطی را در Vercel بگذارید (`STANDALONE=true` و بقیه).
3. `DATABASE_URL` را از Neon کپی کنید.
4. دامنه را در Vercel اضافه کنید و DNS را طبق جدول زیر بزنید.

### Docker روی سرور

```bash
cp .env.example .env
# مقادیر را پر کنید
docker compose up -d --build
```

### DNS (وقتی میزبان آماده شد)

اگر روی Vercel است:

| Type | Name/Host | Value/Target | TTL |
|---|---|---|---|
| A | @ | `10.0.1.2` | 300 |
| CNAME | www | `cname.vercel-dns.com` | 300 |

اگر A فعلی Vercel فرق داشت، همان مقدار پنل Vercel را بگذارید. تا وقتی میزبان قطعی نشده این جدول را در DNS وارد نکنید.

## توسعه محلی

```bash
npm ci
npm run dev
```

بدون `DATABASE_URL` از پایگاه موقت داخل پردازش استفاده می‌شود (داده‌ها با ری‌استارت پاک می‌شوند). این فقط برای پیش‌نمایش است.

## پشتیبان

```bash
DATABASE_URL=... npm run backup
```

خروجی JSON جداول اصلی در پوشه `backups/`.

## امنیت

رمز، کلید پایگاه و کلید API داخل کد نیستند. کوکی نشست `__Host-` و HTTPS است. رزرو و نمایش نقشه برای کسب‌وکار منقضی‌شده در سرور رد می‌شود.
