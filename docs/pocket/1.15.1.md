## SMS: full website template set in the app
The app imports the website's own template functions (single source), so the texts match the site exactly, newlines and placeholders included. `src/lib/pocket/sms-templates.ts` maps each kind to its source.

| kind | label group | source function |
|---|---|---|
| confirm | booking | `bookingConfirmSms` (tattoo-flow.ts) |
| reminder | booking | `bookingReminderSms` |
| card | payment | `depositCardSms` (+ `paymentDetailsText`) |
| balance | payment | `balanceSms` |
| prep | before session | `prepBeforeTattooSms` |
| food | before session | `sessionFoodSms` |
| care-guide | aftercare | `aftercareGuideSms` |
| care-wash / care-itch / care-month | aftercare (آقا/خانم choice) | `aftercareSms` |
| proposal-seen | design (آقا/خانم choice) | `proposalSeenSms` |
| fillin-offer / fillin-missed / fillin-registered | free slot | `fillInOfferSms`, `fillInMissedCallSms`, `fillInRegisteredSms` |
| trainee-joined | trainee | `apprenticeJoinedSms` (studio-apprentices.ts) |
| trainee-thursday | trainee | `apprenticeThursdaySms` |
| trainee-practice | trainee | `apprenticePracticeSms` |

The count went from 6 (site-imported bookings only) to 17: 14 booking and 3 trainee. Booking templates are now also offered for local tattoo bookings. The time comes from the Jalali day plus the time (Tehran); a warning is shown when the time or price is missing.

The preview shows the full text, which can be edited for this one message. There is a آقا/خانم toggle and a phone choice. You can copy the text or open the phone's SMS app via an encoded `sms:` link. **Nothing is sent automatically.** There is no SMS history and no stored overrides. tel, WhatsApp and Instagram links stay outside the license gate.

**Not included:** the referral-club SMS (`fillClubSms`). It depends on owner settings stored on the server and stays website-only.
