# Pocket 1.15.3-test (versionCode 25): owner activation fix

APK: https://kasbokarapp.netlify.app/downloads/taghvim-nobat-colorful-1.15.3-test.apk (sha256 `f6b7d2897f25413dfc99cb28627e442537fbb28f381572e41c03725bd501c880`). Same package, same signer (`be4b8113…6ed5e`). The only pinned key is production `k5a4a2fcea4e503b7`, the same as the server's live `/api/pocket-license` key. Earlier releases are unchanged.

## What was wrong
The owner path was already in place:
- **Server:** `pocketLicenseSelf` in `/api/save` needs a real site session (401 without one), then the studio-owner role plus `requireAdmin` (403 otherwise). It upserts a 1-year, 5-device self license bound to the device id and returns a signed token.
- **Native:** `selfPocketLicense` reads the WebView CookieManager cookie for kasbokarapp.com only and posts to the fixed endpoint. The token is never passed in a URL.

The problem was in the app UI flow:
1. Tapping «ورود صاحب برنامه» with no site session got 401, and the site login opened.
2. After login, `finishPocketLogin()` reloaded the offline page, but **nothing requested the self license again**. The screen stayed on «فعال‌سازی برنامه» until the user happened to tap the button a second time.

## Fix (app only; no server or key change)
- A pending marker `pocket.license.ownerPending.v1` (timestamp only, valid 30 minutes) is set when the login is opened.
- On the reloaded page and on foreground (`pocket-account-refresh`), if the license is not valid, the app calls `selfPocketLicense` automatically. The same install device id is used before and after the login.
- **Results:**
  - 200: token stored and verified offline against the pinned key, all features unlocked.
  - 401: clear message, no login loop.
  - 403: "this site account is not the owner".
- The card now explains that the owner needs no code, and the button says «ورود صاحب برنامه (فعال‌سازی خودکار، بدون کد)».
- **Renewal is not automatic:** the self license lasts 1 year from issue (each new owner sign-in extends it to 1 year from then). Normal refresh renews only the offline lease, not the 1 year.

## What the owner does on the phone
1. Install 1.15.3 over the existing app. Data stays.
2. On the «فعال‌سازی برنامه» card, tap «ورود صاحب برنامه (فعال‌سازی خودکار، بدون کد)».
3. On the site page that opens, sign in with the site's owner account.
4. Return to the app (automatic after login, or use the return bar). The card should change to «مجوز صاحب برنامه فعال است» with an expiry date.
5. If it says the account is not the owner, sign out on the site and sign in with the owner account. If it says no session was found, repeat step 2.
